# Expense Tracker

A simple expense management application built with Next.js and React.

The app allows users to record income and expenses, track their balance, organize transactions, and manage their financial data directly in the browser.

## Live Demo

https://mooncakegt.github.io/expense-tracker/

## Features

- Add income and expense transactions
- Track total balance, income, and expenses
- Remove transactions
- Sort transactions by:
  - Newest
  - Oldest
  - Highest amount
  - Lowest amount
- Import transactions from CSV
- Export transactions to CSV
- Persistent data storage using browser localStorage
- Currency formatting using Malaysian Ringgit (MYR)

## Technologies Used

- Next.js 16
- React
- JavaScript
- Bootstrap
- PapaParse
- LocalStorage API
